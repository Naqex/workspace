# Miro snapshots — lịch sử tháng 09/2026

Các SVG và `board-manifest.json` giữ nguyên bytes của snapshot cũ, được chuyển
từ `miro/` vào archive. Đường dẫn/tên project trong manifest là nguồn gốc lịch
sử, không là cấu hình runtime hay source hiện hành. Snapshot hiện nằm cạnh
manifest; source sản phẩm hiện hành là `projects/trader/` tại workspace root.

Không replay snapshot để ghi đè board. Đọc lại board thật và instruction hiện
hành trước khi dùng công cụ Miro; repo không cấp quyền sửa/chia sẻ board.
