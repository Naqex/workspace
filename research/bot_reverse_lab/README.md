# Bot Lab

Đặt bản sao bot bạn có quyền phân tích vào `inbox/` (Git ignore). Không chạy
sample trong terminal, Python hoặc MT5. Source/binary inspection và log
fingerprint chỉ tạo bằng chứng; không tự khôi phục thuật toán hoặc cấp quyền trade.

Hướng dẫn: [playbook](../../planning/research/BOT-REVERSE-LAB-PLAYBOOK.md).
